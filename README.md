**核心功能使用指南：**
2.1 会议录音与实时转写
点击底部控制栏的红色录制按钮 即可开始录音，系统将同时录制麦克风和系统音频，并实时显示转写文本。录音过程中可随时暂停或继续，点击停止按钮结束录音并保存会议记录。
录音停止后，系统会自动进行说话人分离处理，识别不同发言者并在转写文本中标注说话人标签（如"说话人1""说话人2"）。如已注册声纹，系统会自动匹配声纹显示真实姓名。说话人分离过程在本地完成，无需联网。您也可以在会议详情页手动指派说话人或重新运行说话人分离。录音时请注意以下事项：
• 确保麦克风和扬声器设备已正确连接并授权
• 首次使用需在系统设置中授予麦克风权限
• 实时转写质量与语音清晰度、背景噪音、模型选择等因素相关
• 可在设置中切换不同大小的模型，平衡速度与准确率
• 说话人分离效果与录音质量、发言人数、背景噪音等因素相关，建议单人发言时尽量减少插话
• 已注册声纹的说话人会自动显示姓名，未注册的显示为数字标签，可在设置-声纹管理中注册
• 说话人分离在录音结束后自动进行，处理时间约为录音时长的1/3至1/2，具体取决于电脑性能
2.2 音频导入与重转写
支持导入已有的音频文件（如MP3、WAV、M4A等格式）生成转写文本。点击左侧边栏的"导入音频"按钮，选择本地音频文件即可开始转写。导入音频时系统会自动运行DeepFilterNet3降噪模型对音频进行预处理，有效降低背景噪音，提升转写准确率。

2.3 AI智能摘要
会议转写完成后，请在下方框中为Al摘要添加上下文。例如参与人员、会议概览、目标等。 
点击"生成摘要"按钮，系统将调用配置的大语言模型对转写内容进行智能分析，生成结构化的会议摘要。摘要内容通常包括：
• 会议要点：提炼会议的核心议题和讨论内容
• 行动项：识别会议中确定的待办事项和责任人
• 决策记录：整理会议达成的重要决策和结论
• 风险提示：标注会议中提及的风险点和注意事项
摘要生成支持自定义模板，可在设置中配置不同的摘要格式以适应不同类型的会议（如日常站会、项目评审、头脑风暴等）。
2.4 会议笔记编辑
系统内置富文本编辑器，可在转写文本的基础上进行编辑整理，添加标注、调整结构、补充内容。编辑器支持标题、列表、加粗、斜体等常见格式，帮助您快速整理出规范的会议纪要。
编辑后的笔记会与原转写文本关联保存，方便对照查看。同时支持将笔记导出为Markdown格式文件。

2.6 模型管理

• 说话人分离模型：Pyannote分段模型与CAM++声纹嵌入模型已内置，采用3D-Speaker框架，识别准确率更高、速度更快，录音停止后自动运行说话人分离，无需额外下载

• 云端LLM：支持OpenAI、Claude、Groq、OpenRouter等多种云端服务商
• 自定义端点：支持配置兼容OpenAI API格式的自定义模型服务端点

在录音控制区域可选择录音设备：

• 智能闪避：自动降低背景噪音，提升语音清晰度

注意：设置弹窗会适配任何分辨率，确保所有文字和UI元素都能正常显示，不会被遮挡。

2.9 声纹管理
声纹管理功能允许您注册常用说话人的声音特征，系统会在说话人分离时自动匹配并显示真实姓名，告别"说话人1""说话人2"的数字标签。声纹数据完全保存在本地，不会上传到任何服务器。
2.9.1 注册新声纹
注册声纹需要从已完成说话人分离的会议中抓取样本，操作步骤如下：
• 1. 点击左下角设置图标，进入设置页面，切换到"声纹管理"标签页
• 2. 点击右上角"添加声纹"按钮，打开注册弹窗
• 3. 从下拉列表中选择一个已完成说话人分离的会议
• 4. 选择要注册的说话人（如"说话人1"）
• 5. 点击"抓取样本"，系统会自动提取该说话人3-10秒的清晰语音样本
• 6. 点击播放按钮可试听抓取的样本，确认声音清晰无误
• 7. 输入说话人姓名，点击"保存"完成注册
2.9.2 声纹识别与使用
声纹注册完成后，系统会在以下场景自动使用：
• 新会议说话人分离：录音停止后自动运行声纹匹配，已注册的说话人直接显示姓名
• 导入音频转写：导入音频完成说话人分离后自动匹配声纹
• 重新识别说话人：在会议详情页可随时重新运行说话人分离，结果会自动匹配声纹
声纹匹配采用余弦相似度算法，阈值为0.6，匹配度高于阈值的说话人会显示注册的姓名。
2.9.3 手动指派说话人
如果自动识别结果不准确，可以在会议详情页手动调整：
• 点击转写文本中的说话人标签，选择"指派给..."
• 从已注册的声纹列表中选择正确的说话人
• 也可以选择"重新识别"，系统会重新运行说话人分离和声纹匹配
2.9.4 管理声纹
在声纹管理页面可以查看和管理所有已注册的声纹：
• 点击播放按钮可试听声纹样本
• 点击删除按钮可移除声纹，关联的说话人指派也会被清除
• 声纹样本来自真实会议录音，建议选择发音清晰、背景安静的片段
提示：声纹识别效果与样本质量密切相关，建议选择3-10秒清晰、无背景噪音的语音样本。同一说话人在不同设备或环境下的声音可能有差异，建议使用与实际会议场景相近的样本。

**常见问题解答：**
Q1：软件启动后没有窗口显示怎么办？
A：请检查系统托盘（Windows右下角/macOS菜单栏）中是否有软件图标，点击图标即可显示主窗口。如果托盘也没有图标，请重启软件。
Q2：转写准确率不够高怎么办？
A：可以尝试以下方法提升准确率：1）使用更大的模型（如medium或large），准确率更高但速度较慢；2）确保录音环境安静，减少背景噪音；3）麦克风距离说话人适中，避免音量过小或过大；4）使用"增强转写"功能，切换更准确的模型重新转写。
Q3：录制的会议数据会传到外网吗？
A：录音和转写全程在本地完成，原始音频和转写文本不会自动上传到外部服务器。但在生成AI摘要时，转写文本会作为上下文发送给您配置的大模型服务商进行处理，因此，请根据会议涉密程度选择合适的模型服务商，敏感会议必须使用本地模型。
Q4：数据保存在哪里？如何备份？
A：所有会议录音、转写文本、摘要数据默认保存在系统数据目录中。备份方式：1）在设置页面中点击"一键备份"，将所有数据导出为压缩包；2）手动复制数据目录下的所有文件。恢复数据时将备份文件放回对应目录即可。
Q5：可以同时录制麦克风和系统声音吗？
A：可以。软件支持同时录制麦克风输入和系统音频输出，适合录制线上会议、视频会议等场景。在录音控制面板中分别选择麦克风设备并开启系统音频录制即可。

Q6：软件支持哪些音频格式的导入？
A：支持导入常见的音频格式，包括MP3、WAV、M4A、FLAC、OGG等。导入后系统会自动转码并进行转写，处理速度取决于音频长度和电脑性能。
Q7：说话人分离可以识别几个人？准确率如何？
A：说话人分离支持自动检测说话人数（不限人数），录音停止后自动运行。分离准确率与录音质量、发言人数、背景噪音等因素相关，清晰的会议录音准确率较高。说话人标签以数字编号表示（说话人1、说话人2...），系统会自动为每段话匹配最合适的说话人。
Q8：可以离线使用吗？
A：录音和转写功能完全离线可用，只要下载了本地语音识别模型即可。AI摘要功能如果使用本地Ollama模型也可完全离线；如果使用云端LLM服务商，则需要联网调用API，由于会议和访谈环境通常涉敏涉密，一般不推荐使用云端服务商。
Q9：转写支持哪些语言？
A：SenseVoice模型支持普通话、粤语、英语、日语和韩语（转录速度快），Whisper模型支持多种语言，包括中文、英文、日文、韩文等近百种语言（转录速度慢）。默认为中文普通话，可在设置中指定识别语言，或选择"自动检测"由系统自动判断。

Q10：声纹识别准确率如何？如何提升？
A：声纹识别采用CAM++模型和余弦相似度算法，清晰语音下准确率较高。提升识别效果的建议：1）使用3-10秒清晰、无背景噪音的语音样本注册；2）样本来源的录音环境与实际会议场景尽量一致；3）说话人数量较多时建议分别注册；4）可以在会议详情页手动修正识别结果。
Q11：导入音频时的降噪处理会影响原始录音文件吗？
A：不会。DeepFilterNet3降噪仅在转写处理过程中对音频数据进行预处理，原始音频文件不会被修改。系统保存的仍然是原始录音文件，降噪后的音频仅用于提升转写准确率。
Q12：可以同时注册多少个声纹？有数量限制吗？
A：声纹注册没有数量限制，可以根据需要注册任意数量的说话人。但建议只注册经常参会的人员，过多的声纹可能会增加匹配时间和误匹配概率。
